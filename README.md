# Diplom_1

Учебный Java-проект с unit-тестами для приложения **Stellar Burgers**.  
Проект проверяет работу классов, отвечающих за создание бургера, выбор булок и ингредиентов, расчет стоимости и формирование чека.

## Описание проекта

В проекте реализована простая модель бургера:

- булка выбирается из доступного списка;
- в бургер можно добавлять ингредиенты;
- ингредиенты можно удалять и менять местами;
- итоговая цена рассчитывается как стоимость двух булок и всех добавленных ингредиентов;
- по составу бургера формируется текстовый чек.

Проект подготовлен как первая часть дипломной работы по автоматизации тестирования.

## Что покрыто тестами

Тестами проверяются:

- создание булки и получение ее названия и цены;
- создание ингредиента и получение его типа, названия и цены;
- наличие доступных булок и ингредиентов в базе данных;
- установка булки в бургер;
- добавление ингредиентов;
- удаление ингредиентов;
- перемещение ингредиентов вперед, назад и в тот же индекс;
- обработка некорректных индексов при перемещении ингредиентов;
- расчет стоимости бургера;
- формирование чека;
- порядок ингредиентов в чеке;
- значения enum `IngredientType`.

Для проверки расчета цены используются параметризованные тесты.
Для изоляции тестов класса `Burger` используются моки `Bun` и `Ingredient`.

## Как запустить проект

### Предварительные требования

Перед запуском должны быть установлены:

- JDK 11 или выше;
- Maven.

Проверить установку можно командами:

```bash
java -version
mvn -version
```

### Клонирование репозитория

```bash
git clone https://github.com/ksmeqq/Diplom_1.git
cd Diplom_1
```

### Запуск тестов

```bash
mvn test
```

После выполнения команды Maven запустит все тесты из директории `src/test/java`.

### Запуск тестов с отчетом JaCoCo

```bash
mvn clean test
```

Отчет о покрытии будет сформирован в директории:

```text
target/site/jacoco/index.html
```

Файл `index.html` можно открыть в браузере.

## Покрытие тестами

В проекте используется JaCoCo.  
По текущему отчету бизнес-классы `Bun`, `Burger`, `Database`, `Ingredient` и `IngredientType` покрыты тестами полностью по строкам.  
Общий процент покрытия ниже из-за класса `Praktikum`, который содержит демонстрационный метод `main`.

## Основные классы

### `Bun`

Модель булки. Хранит название и цену.

### `Ingredient`

Модель ингредиента. Хранит тип, название и цену.

### `IngredientType`

Enum с типами ингредиентов:

- `SAUCE` - соус;
- `FILLING` - начинка.

### `Burger`

Класс для сборки бургера. Позволяет:

- выбрать булку;
- добавить ингредиент;
- удалить ингредиент;
- переместить ингредиент;
- рассчитать цену;
- получить чек.

### `Database`

Класс с тестовыми данными. Возвращает списки доступных булок и ингредиентов.
